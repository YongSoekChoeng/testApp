## 현업요청

A. 이미지 게시판 개발
	<기능>
	1. 목록화면
	  - 등록된 이미지 게시물 목록이 보여진다.
	  - 페이징 처리.
	  - 테이블 항목
	    체크박스, SEQ, 썸네일, 제목, 등록자
	  - 조회조건
		제목
	  - 기능버튼
		a. 전체선택: 클릭 시 체크박스 전체가 체크된다.
		b. 등록: 새로운 게시물을 등록할 수 있는 상세화면팝업이 편집모드로 노출.
		c. 삭제: 체크된 게시물들을 삭제.
	  - 이벤트
		a. 목록에서 제목 클릭 시 상세화면팝업이 조회모드로 노출.
		b. 목록에서 썸네일 클릭 시 이미지 팝업 노출.
	2. 상세화면
	  - 항목
		제목, 등록자(로그인 사용자명 자동세팅), 파일업로드버튼.
	  - 기능버튼
		a. 파일업로드버튼 클릭 시 로컬에 있는 이미지 선택 가능.
		b. 저장버튼 클릭 시 등록내용 저장.
		c. 수정버튼 클릭 시 등록내용 수정.
	<메뉴위치>
