# 요구사항 정의서

## 배경/목적
- 로그 조회 메뉴(로그인이력, 액션로그, 에러로그) 이용 시 발생하는 SQL 문법 에러를 수정하여 정상적인 로그 조회가 가능하도록 함.

## 기능 요구사항
### FR-01: 로그인 이력 조회 에러 수정
- **Given**: 사용자가 '테스트 > 로그조회 > 로그인이력' 메뉴에서 로그 조회를 요청할 때
- **When**: `logs.selectLoginHistList` 쿼리가 실행될 때
- **Then**: SQL 내 `ORDER BY seq desc` 구문에서 발생하는 `Unknown column ''seq'` 에러가 발생하지 않고 데이터가 정상적으로 조회되어야 함.

### FR-02: 액션로그 및 에러로그 메뉴 정상화
- **Given**: 사용자가 '테스트 > 로그조회 > 액션로그' 또는 '에러로그' 메뉴에 접근할 때
- **When**: 해당 메뉴의 데이터 조회 쿼리가 실행될 때
- **Then**: 에러 없이 데이터가 화면에 정상적으로 출력되어야 함.

## 비기능 요구사항
- **감사로그**: 로그 조회 시 발생하는 에러를 방지하여 시스템의 가용성을 확보함.

## 범위 제외 항목
- 로그 데이터 자체의 정합성 검증 (데이터가 맞는지 틀린지는 확인 대상이 아님)
- UI/UX 디자인 변경

## 확인 필요 질문
1. `ORDER BY seq desc`에서 사용된 `seq` 컬럼이 실제 DB 테이블(`tbsy_login_hist` 또는 `tbin_empmst`)에 존재하는 컬럼인지, 아니면 다른 컬럼(예: `login_dtm`)으로 대체해야 하는지 확인이 필요합니다.
2. `logs-mapper.xml` 내의 다른 쿼리들에서도 유사한 컬럼 참조 오류가 있는지 확인이 필요합니다.
