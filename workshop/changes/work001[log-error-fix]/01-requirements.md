# 요구사항 정의서

## 배경/목적
- 로그 조회 메뉴(로그인이력, 액션로그, 에러로그)에서 발생하는 SQL 문법 오류를 해결하여 정상적인 로그 조회가 가능하도록 함.

## 기능 요구사항
### FR-01: 에러 로그 리스트 조회 오류 수정
- **Given**: 사용자가 '테스트 > 로그조회 > 에러로그' 메뉴에서 로그 조회를 요청할 때
- **When**: 시스템이 `logs-mapper.xml`의 `selectErrorLogList` 쿼리를 실행할 때
- **Then**: `ORDER BY seq DESC`와 같이 존재하지 않는 컬럼(`seq`)을 참조하는 구문이 제거되거나 유효한 컬럼으로 대체되어 에러 없이 데이터가 조회되어야 한다.

## 비기능 요구사항
- **가용성**: 로그 조회 기능은 에러 없이 정상적으로 동작하여 관리자가 로그를 확인할 수 있어야 한다.

## 범위 제외 항목
- 인사/조직 모듈(insa/org) 관련 기능

2. `selectActionLogList` 쿼리에서도 동일한 정렬 오류가 발생할 가능성이 있는지 확인이 필요합니다. (현재 소스상으로는 `selectErrorLogList`에서만 명확한 오류가 발견됨)
