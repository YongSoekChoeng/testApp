# 요구사항 정의서: 로그 조회 메뉴 에러 수정

## 배경/목적
- 테스트 메뉴(로그인 이력, 액션 로그, 에러 로그) 조회 시 발생하는 SQL 문법 에러를 해결하여 정상적인 로그 조회가 가능하도록 함.

## 기능 요구사항
### FR-01: 에러 로그 리스트 조회 기능 수정
- **Given**: 사용자가 '테스트 > 로그조회 > 에러로그' 메뉴에 접속하여 로그 리스트를 조회하려고 함.
- **When**: 로그 리스트 조회 요청 시 `selectErrorLogList` 쿼리가 실행됨.
- **Then**: SQL 문 내의 존재하지 않는 컬럼인 `seq`를 사용하여 정렬(`ORDER BY seq desc`)을 시도하여 발생하는 `Unknown column 'seq' in 'order clause'` 에러가 발생하지 않도록 수정되어야 함. (예: `in_dtm` 등 존재하는 컬럼으로 정렬 변경)

### FR-02: 액션 로그 리스트 조회 기능 정상화 (잠재적 이슈 대응)
- **Given**: 사용자가 '테스트 > 로그조회 > 액션로그' 메뉴에 접속하여 로그 리스트를 조회하려고 함.
- **When**: 로그 리스트 조회 요청 시 `selectActionLogList` 쿼리가 실행됨.
- **Then**: 에러 로그와 마찬가지로 정렬 조건에 존재하지 않는 컬럼(`seq`)이 사용되고 있다면, 존재하는 컬럼(예: `in_dtm`)으로 수정되어야 함.

### FR-03: 로그인 이력 리스트 조회 기능 정상화 (잠재적 이슈 대응)
- **Given**: 사용자가 '테스트 > 로그조회 > 로그인이력' 메뉴에 접속하여 로그 리스트를 조회하려고 함.
- **When**: 로그 리스트 조회 요청 시 `selectLoginHistList` 쿼리가 실행됨.
- **Then**: 정렬 조건에 존재하지 않는 컬럼(`seq`)이 사용되고 있다면, 존재하는 컬럼(예: `login_dtm`)으로 수정되어야 함.

## 비기능 요구사항
- **감사로그**: 로그 조회 기능의 수정이 기존의 로그 기록(Insert) 기능에 영향을 주지 않아야 함.
- **성능**: 페이징 처리가 포함된 쿼리이므로, 수정된 정렬 조건이 인덱스를 효율적으로 활용할 수 있어야 함.

## 범위 제외 항목 (Out of scope)
- 인사/조직 모듈(insa/org) 관련 기능 수정.
- 로그 데이터 자체의 삭제 또는 변경.

## 확인 필요 질문
1. `selectErrorLogList` 쿼리에서 `seq` 대신 사용할 기본 정렬 기준 컬럼이 무엇입니까? (현재 로그 파일 상으로는 `in_dtm`이 적절해 보입니다.)
2. `selectActionLogList` 및 `selectLoginHistList` 쿼리에서도 동일하게 `seq` 컬럼을 사용한 정렬 에러가 발생하는지 확인이 필요합니다. (현재 에러 로그는 `selectErrorLogList`에 집중되어 있으나, 다른 메뉴도 동일한 패턴의 오류가 의심됩니다.)
3. `Comm.PagingStart` 및 `Comm.PagingEnd` 내부에서 `seq` 컬럼을 강제로 참조하고 있는지 확인이 필요합니다.
