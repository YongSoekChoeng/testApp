# 요구사항 정의서: 로그 조회 메뉴 에러 수정

## 배경/목적
- 테스트 메뉴의 로그 조회 기능(로그인이력, 액션로그, 에러로그)에서 SQL 문법 오류로 인한 에러가 발생하여 이를 수정하고 정상적인 로그 조회가 가능하도록 함.

## 기능 요구사항
### FR-01: 로그인 이력 조회 기능 수정
- **Given**: 사용자가 '테스트 > 로그조회 > 로그인이력' 메뉴에 접속하여 조회 조건을 설정함.
- **When**: 로그인 이력 목록 조회(Ajax)를 요청함.
- **Then**: SQL 쿼리 내 존재하지 않는 컬럼(`seq`)을 참조하여 발생하는 `Unknown column 'seq' in 'order clause'` 에러가 해결되어, 데이터가 정상적으로 조회되어야 함.

### FR-02: 액션 로그 조회 기능 정상화
- **Given**: 사용자가 '테스트 > 로그조회 > 액션로그' 메뉴에 접속함.
- **When**: 액션 로그 목록 조회(Ajax)를 요청함.
- **Then**: 액션 로그 데이터가 정상적으로 조회되어야 함.

### FR-03: 에러 로그 조회 기능 정상화
- **Given**: 사용자가 '테스트 > 로그조회 > 에러로그' 메뉴에 접속함.
- **When**: 에러 로그 목록 조회(Ajax)를 요청함.
- **Then**: 에러 로그 데이터가 정상적으로 조회되어야 함.

## 비기능 요구사항
- **감사로그**: 로그 조회 시 발생한 SQL 에러가 시스템 전체의 안정성을 해치지 않도록 예외 처리가 적절히 이루어져야 함.

## 범위 제외 항목 (Out of scope)
- 인사/조직 모듈(insa/org) 관련 기능 (현재 프로젝트 범위 제외 항목임)
- 로그 데이터의 삭제 또는 수정 기능

## 확인 필요 질문
1. `selectLoginHistList` 쿼리에서 `ORDER BY seq DESC`를 사용 중인데, `seq` 대신 사용해야 할 정렬 기준 컬럼(예: `login_dtm` 등)이 무엇인지 확인이 필요합니다.
2. `ActionLogVO`와 `ErrorLogVO`를 사용하여 조회할 때, `logs-mapper.xml` 내의 `selectActionLogList` 및 `selectErrorLogList` 쿼리에서도 유사한 정렬 오류가 발생할 가능성이 있는지 검토가 필요합니다. (현재 로그상으로는 `selectLoginHistList`에서만 명확한 에러가 확인됨)
