# 요구사항 정의서: 로그 조회 메뉴 에러 수정

## 배경/목적
- 로그 조회 메뉴(로그인이력, 액션로그, 에러로그) 이용 시 발생하는 SQL 문법 에러를 해결하여 정상적인 로그 조회가 가능하도록 한다.

## 기능 요구사항 (FR)

### FR-01: 로그인 이력 조회 기능 수정
- **Given**: 사용자가 '테스트 > 로그조회 > 로그인이력' 메뉴에 접속하여 조회 조건을 설정한다.
- **When**: 로그인 이력 목록 조회를 요청한다.
- **Then**: `Unknown column 'seq' in 'order clause'` 에러 없이 로그인 이력 목록이 정상적으로 출력되어야 한다. (SQL 내 존재하지 않는 `seq` 컬럼을 통한 정렬 로직 수정 필요)

### FR-02: 액션 로그 조회 기능 수정
- **Given**: 사용자가 '테스트 > 로그조회 > 액션로그' 메뉴에 접속한다.
- **When**: 액션 로그 목록 조회를 요청한다.
- **Then**: 에러 없이 액션 로그 목록이 정상적으로 출력되어야 한다. (로그 파일의 에러 패턴을 분석하여 `selectActionLogListSql` 내 정렬 컬럼 확인 및 수정)

### FR-03: 에러 로그 조회 기능 수정
- **Given**: 사용자가 '테스트 > 로그조회 > 에러로그' 메뉴에 접속한다.
- **When**: 에러 로그 목록 조회를 요청한다.
- **Then**: 에러 없이 에러 로그 목록이 정상적으로 출력되어야 한다. (로그 파일의 에러 패턴을 분석하여 `selectErrorLogListSql` 내 정렬 컬럼 확인 및 수정)

## 비기능 요구사항
- **감사로그**: 로그 조회 기능 수정 시 기존의 로그 기록 및 조회 기능이 유지되어야 한다.
- **안정성**: SQL 문법 오류로 인해 서비스 프로세스가 중단되지 않도록 예외 처리가 적절히 수행되어야 한다.

## 범위 제외 항목 (Out of scope)
- 인사/조직 모듈(insa/org) 관련 기능 수정 (현재 프로젝트 범위 제외 사항)
- 로그 데이터 자체의 정합성 검증 및 데이터 수정

## 확인 필요 질문
1. `selectLoginHistListSql`에서 `ORDER BY seq desc`로 되어 있는 부분의 `seq` 대신 사용해야 할 올바른 정렬 기준 컬럼은 무엇입니까? (예: `login_dtm` 등)
2. 액션로그 및 에러로그의 경우, 현재 `error.log` 상에는 `selectLoginHistList`의 에러만 명시적으로 나타나 있습니다. 액션로그와 에러로그 메뉴에서도 동일한 `seq` 관련 SQL 에러가 발생하는지 확인이 필요합니다.
3. `LoginHistVO`에서 `net.sf.json.JSONObject toBean` 호출 시 발생하는 `Tried to assign property` 경고(Warning)도 이번 수정 범위에 포함됩니까? (VO 클래스에 해당 필드가 누락된 것으로 보임)
