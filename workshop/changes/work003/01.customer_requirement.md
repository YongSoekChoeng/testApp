## 1. 수정사항 (A. 에러수정)

### TASK-01 | 로그조회 3개 메뉴(로그인이력/액션로그/에러로그) 조회 에러 수정
- **목적**: 테스트>로그조회>로그인이력·액션로그·에러로그 3개 메뉴에서 발생하는 조회 에러를 수정하여 목록이 정상 조회되게 한다.
- **대상 파일 절대경로**:
  - D:/AppHome/testApp/src/main/resources/sqlmap/mapper/system/logs-mapper.xml
    (`selectLoginHistListSql` / `selectActionLogListSql` / `selectErrorLogListSql`)
  - (보조, 필요 시) D:/AppHome/testApp/src/main/webapp/WEB-INF/views/logs/loginHist.jsp
  - (보조, 필요 시) D:/AppHome/testApp/src/main/webapp/WEB-INF/views/logs/actionLog.jsp
  - (보조, 필요 시) D:/AppHome/testApp/src/main/webapp/WEB-INF/views/logs/errorLog.jsp
- **변경 내용**:
  - 3개 JSP 모두 `sort_column` 은 `seq desc` 로 고정하고 그리드에 `seq`(번호) 컬럼을 표시한다.
  - 그러나 3개 조회 SQL(`selectLoginHistListSql` 등)은 `seq` 컬럼을 SELECT 하지 않는다.
  - 공통 페이징 조각 `Comm.PagingEnd`(comm-mapper.xml)가 `ORDER BY ${sort_column}` 을 실행하므로 `ORDER BY seq desc` → **`Unknown column 'seq' in 'order clause'`** 에러로 추정.
  - logs-mapper.xml 헤더 주석에 "Oracle 시퀀스 seq를 MySQL AUTO_INCREMENT로 바꾸고 조직 조인은 제거했다"고 명시 → seq 컬럼은 테이블에 존재하나 SELECT에서 누락된 것으로 추정.
  - 수정 방향(택 1): ① 3개 SQL의 SELECT에 `tb1.seq`(테이블 PK/AUTO_INCREMENT) 컬럼을 추가하거나, ② 3개 JSP의 `sort_column` 을 실제로 SELECT되는 컬럼(예: `login_dtm desc` / `in_dtm desc`)으로 변경하고 번호 컬럼 처리를 조정.
  - **확인 필요**: 실제 에러 메시지(요청서에 미기재), 3개 로그 테이블(`tbsy_login_hist`/`tbsy_action_log`/`tbsy_error_log`)의 PK·seq 컬럼명, 수정 방향(①/②) 확정.
- **선행 태스크**: 없음
- **완료 기준**: 3개 메뉴 모두 조회 시 에러 없이 목록이 표시되고, 번호 표시·정렬이 정상 동작한다.
- **상태**: 통과
